# Materiais das Olimpíadas

Esta pasta reúne os principais materiais de apoio para as competições do Olympius.

## Estrutura

- `oba/` — Olimpíada Brasileira de Astronomia
- `obmep/` — Olimpíada Brasileira de Matemática
- `obr/` — Olimpíada Brasileira de Robótica
- `onee/` — Olimpíada Nacional de Eficiência Energética

## Como usar

1. Abra o menu de materiais no site.
2. Escolha a olimpíada desejada.
3. Clique no item para baixar o material.

## Objetivo

Os materiais foram organizados para ajudar na revisão, no treino e na preparação para provas e simulados.
