# OBA — Estratégias de resolução

## Como resolver bem os problemas da OBA
- Leia o enunciado com atenção antes de calcular.
- Identifique as grandezas e as relações entre elas.
- Use unidades consistentes.
- Quando houver figuras, interprete os dados antes de responder.

## Verificação final
- Faça uma checagem de ordem de grandeza.
- Compare a resposta com o contexto da questão.
- Revise se a conclusão faz sentido no cenário astronômico.
